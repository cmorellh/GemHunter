# Gem Hunter

A collect-them-all mining game built in Unreal Engine 5, where every gem comes from a real place on Earth (and later, from space). Working title.

**Status:** pre-production. See the [Game Design Plan](docs/Game%20Design%20Plan.md).

## Layout

- `docs/` design documents
- `data/` gem and locality data (CSV/JSON imported as Unreal DataTables)

## Requirements

- Unreal Engine 5 (exact version TBD, set by the chosen voxel terrain plugin)
- [Git LFS](https://git-lfs.com/): run `git lfs install` before cloning
